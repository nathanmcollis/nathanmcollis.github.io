NATHAN COLLIS PORTFOLIO SITE
============================

FILES
- index.html   : page structure
- styles.css   : spacing, typography, image sizing and click zones
- script.js    : project content + navigation behaviour
- assets/      : supplied image/video files

HOW TO EDIT
1. Open this folder in Visual Studio Code.
2. Use the Live Server extension (or any local web server) to preview index.html.
3. Edit client/project text, descriptions and image order in the `projects` array
   near the top of script.js.
4. Edit exact spacing/type in the CSS variables at the top of styles.css.

NAVIGATION
- click left side: previous project
- click middle: next image/page; after a project's last image it moves onward
- click right side: next project
- after the last project the site loops back to the first

BABS + HENRY
The phone PNG is layered over the supplied MP4. The video autoplays muted and
loops while that page is visible, as shown in the annotated coding plan.
